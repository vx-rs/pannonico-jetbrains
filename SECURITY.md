# Security policy

Report suspected Pannonico JetBrains plugin vulnerabilities through the shared
[GitHub private vulnerability reporting form](https://github.com/vx-rs/pannonico/security/advisories/new).
Do not disclose vulnerability details in this repository's public Issues.

Include the plugin and pinned LSP versions, JetBrains IDE name and build,
operating system and architecture, reproduction steps, impact, and any
suggested mitigation. Remove credentials, personal data, and confidential
project content.
