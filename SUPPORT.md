# Support

Use [pannonico-jetbrains Issues](https://github.com/vx-rs/pannonico-jetbrains/issues)
for plugin installation, compatibility, acquisition, and lifecycle reports.
Search existing issues before opening a new one.

Include the plugin and LSP versions, JetBrains IDE name and build, operating
system and architecture, project marker, reproduction steps, expected and
actual behavior, and redacted IDE logs. Remove credentials, personal data,
private paths, and confidential project content.

Suspected vulnerabilities use the private process in
[SECURITY.md](SECURITY.md), not a public issue.
